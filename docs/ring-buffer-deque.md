# Ring Buffer

Кольцевой буфер — универсальная структура данных на основе массива фиксированной вместимости. Поддерживает добавление и извлечение элементов за O(1), циклически перемещаясь по массиву.

## Structure

| Поле | Описание |
|---|---|
| `data` | Массив хранимых элементов |
| `capacity` | Максимальное количество элементов |
| `elem_size` | Размер одного элемента в байтах |
| `head` | Индекс следующего элемента для чтения |
| `tail` | Индекс следующей позиции для записи |
| `size` | Текущее количество элементов |

## Methods

| Метод | Возвращаемое значение | Описание |
|---|---|---|
| `ring_buffer_create(capacity, elem_size)` | `RingBuffer*` | Создание буфера и выделение памяти |
| `ring_buffer_destroy(rb)` | `void` | Освобождение памяти |
| `ring_buffer_push(rb, value)` | `bool` | Добавление элемента в конец |
| `ring_buffer_pop(rb, out)` | `bool` | Извлечение и удаление первого элемента |
| `ring_buffer_peek(rb, out)` | `bool` | Чтение первого элемента без удаления |
| `ring_buffer_is_empty(rb)` | `bool` | Проверка на пустоту |
| `ring_buffer_is_full(rb)` | `bool` | Проверка на заполненность |
| `ring_buffer_clear(rb)` | `void` | Очистка буфера |

## Behavior

- Универсальное хранение элементов произвольного типа через `elem_size`.
- Фиксированная вместимость.
- При заполнении `push()` возвращает `false`.
- При пустом буфере `pop()` и `peek()` возвращают `false`.
- `pop()` и `peek()` записывают результат через выходной указатель `out`.
- После достижения конца массива индексы переходят в начало.
- Удаление элемента не требует физической очистки ячейки.
- Все операции добавления и извлечения выполняются за O(1).
